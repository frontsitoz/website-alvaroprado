# Álvaro Prado — Frontend Developer Portfolio

Personal portfolio website built to showcase my experience, technical skills, projects, and background as a Frontend Developer.

The project was developed with **Vue 3, TypeScript, Tailwind CSS, and Vite**, following a component-based approach to create a responsive, maintainable, and modern user interface.

## 🛠️ Installation

Clone the repository:

```bash
git clone https://github.com/frontsitoz/website-alvaroprado.git
```

Go to the project directory:

```bash
cd website-alvaroprado
```

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

---

## 📦 Production Build

To generate a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
